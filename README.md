# Mfesane Kunju — Data & Technology Portfolio

A responsive personal portfolio built with plain HTML, CSS and vanilla JavaScript. It is designed to be hosted on GitHub Pages.

## Files

- `index.html` — page content and semantic structure.
- `style.css` — layout, colours, typography, responsive design and project-card visuals.
- `script.js` — mobile navigation, project filters and dynamic footer year.

## Run locally

1. Download and unzip the portfolio.
2. Open `index.html` in a browser.
3. For a local development server, open the folder in VS Code and use a local server extension, or run `python -m http.server 8000` from this directory and visit `http://localhost:8000`.

No build tools, packages or API keys are required.

## Publish with GitHub Pages

1. Create a new **public** repository on GitHub, for example `mfesane-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The URL will be shown in the Pages settings; for a repository named `mfesane-portfolio`, it will usually be `https://mfessy89.github.io/mfesane-portfolio/`.

## Before publishing

- Check every project link and update it if a repository has moved or been renamed.
- Add screenshots and a README to each featured project repository.
- Review the wording of the skills section so it accurately reflects your current level.
- Do not publish participant data, confidential lab information, internal reports, or employer-owned material.
- If you create a repository named exactly `Mfessy89.github.io`, GitHub Pages can publish it as your profile site at `https://mfessy89.github.io/`. Otherwise, the repository name appears in the URL path.
